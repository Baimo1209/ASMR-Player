# 白沫播放器

白沫播放器是一款安卓本地 ASMR 音声播放器，用于管理和播放手机文件夹中的音频、图片与 WebVTT 同步台词。应用以“作品列表”为主页面，适配类似 `RJ01534688/1-普通版/MP3` 的作品目录结构。

## 功能特性

- 支持 `.mp3` 和 `.wav` 音频播放。
- 使用安卓系统文件夹选择器读取目录，不申请宽泛存储权限。
- 递归扫描所选文件夹，自动识别并分组为不同作品。
- 支持常见作品结构，例如：
  - `RJ01534688/1-普通版/MP3/01 说明音轨.mp3`
  - `RJ01534688/1-普通版/MP3/01 说明音轨.mp3.vtt`
- 主页面显示作品封面、作品名称和音轨数量。
- 作品列表可上下滑动浏览，并支持长按作品后点击目标位置调整显示顺序。
- 点击作品进入音轨页面，点击音轨进入播放页面，支持快速逐级返回。
- 播放时显示同作品文件夹下的图片和 `.vtt` 同步台词。
- 播放页图片使用完整显示模式，避免封面被裁切。
- 同一音轨存在多张候选图片时，可在播放页点击图片进行轮播切换。
- 支持 `track.vtt` 和 `track.mp3.vtt` 两种台词命名方式。
- 当前台词会保持显示，直到下一段台词开始。
- 台词页面可上下滑动查看完整台词，点击某段台词可跳转到对应播放位置。
- 音轨列表支持长按某一首进入移动模式，再点击目标位置调整顺序。
- 播放/暂停和台词入口使用图标按钮，界面更简洁。
- 返回作品页或音轨页后保持播放，底部迷你播放条支持暂停、上一首、下一首和回到播放页。

## 安装

在 GitHub Release 中下载 `BaimoPlayer-v1.0.0-debug.apk`，复制到安卓手机并允许安装未知来源应用后安装。

## 构建

本工作区已经安装了本地 Android SDK 和 Gradle 发行包，可直接执行：

```powershell
.\build-apk.ps1
```

The installable debug APK is written to:

```text
BaimoPlayer-v1.0.0-debug.apk
```

## 目录匹配规则

- 音频：`.mp3`、`.wav`
- 图片：`.jpg`、`.jpeg`、`.png`、`.webp`、`.bmp`
- 台词：`.vtt`
- 优先匹配同名图片和同名台词；没有同名图片时，使用作品目录中的第一张图片作为封面。
