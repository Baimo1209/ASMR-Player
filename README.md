# ASMR Player

前言：codex神力制作，之前一直苦于没有好用的安卓ASMR播放软件，这个基本上所有下载的ASMR音声文件放在文件夹中都能生成列表，图片预览，选择播放，台词轮播跳转，总之该有的都有啦，很方便的啦，UI是我按照个人怎么爽怎么来的，总之就是欢迎尝试！QAQ

源码就在这里应该也不用担心有病毒，包体非常非常小只有不到1MB，也欢迎提出意见。

ASMR Player 是一款面向安卓手机的本地 ASMR 音声播放器。它适合管理下载到本地的音声作品目录，尤其是类似 `RJ01534688/1-普通版/MP3` 这样的多层作品结构。应用会从系统文件夹选择器读取用户选择的目录，递归扫描音频、图片和 WebVTT 台词文件，并自动整理成作品列表、音轨列表和播放页面。

应用本身仍显示为“白沫播放器”，GitHub 项目名使用更通用的 **ASMR Player**，方便公开展示和搜索。

## 核心体验

- 作品列表作为主页面，可上下滑动浏览所有识别到的作品。
- 每个作品显示封面、作品名称和音轨数量。
- 点击作品进入音轨列表，点击音轨进入播放页。
- 页面支持逐级返回，播放中的音轨不会因为返回列表而中断。
- 非播放页底部显示迷你播放条，可暂停、上一首、下一首，并可快速回到播放页。
- 首次选择文件夹后会缓存识别结果和排序，下次进入应用会直接预加载作品列表。
- 采用上深下浅的主页结构、圆角内容面板、轻量卡片列表和悬浮胶囊迷你播放器。
- 底部导航包含“听过 / 我的 / 设置”；“听过”会记录近期播放音频并支持跳转播放。
- 应用会进入沉浸式模式，尽量隐藏系统状态栏和底部导航栏，减少遮挡。
- 设置页内提供 GitHub 项目入口，欢迎提交问题、建议和支持。

## 文件识别

ASMR Player 使用 Android 系统文件夹选择器读取用户授权的目录，不申请宽泛存储权限。扫描逻辑支持递归识别：

- 音频：`.mp3`、`.wav`
- 图片：`.jpg`、`.jpeg`、`.png`、`.webp`、`.bmp`
- 台词：`.vtt`

典型目录结构：

```text
RJ01534688/
  1-普通版/
    MP3/
      01 说明音轨.mp3
      01 说明音轨.mp3.vtt
      02 第0人.mp3
      02 第0人.mp3.vtt
```

台词匹配支持两种常见命名：

```text
track.vtt
track.mp3.vtt
```

图片匹配优先级：

1. 与音轨同名的图片
2. 音轨同目录内的图片
3. 作品目录内的其他图片

## 缓存与排序

- 应用会记录上一次选择的文件夹、识别到的文件列表、作品顺序和音轨顺序。
- 进入应用时优先加载本地缓存，不重复扫描文件夹，从而更快进入长期使用列表。
- 只有再次点击“选择文件夹”时才会重新扫描目录。
- 重新扫描时会保留已有作品和音轨的手动排序，新增音声会排列到列表最前方。
- 删除或移走的文件会在重新扫描后从列表中移除。

## 播放功能

- 支持 `.mp3` 和 `.wav` 播放。
- 播放页显示当前音轨、作品信息、播放进度、图片和同步台词。
- 播放页图片使用完整显示模式，避免封面被裁切。
- 同一音轨存在多张候选图片时，可点击播放页图片进行轮播切换。
- 支持上一首、下一首、前后 15 秒跳转。
- 播放/暂停与台词入口使用图标按钮，界面更简洁。

## 台词功能

- 播放页显示当前 WebVTT 台词。
- 当前台词会保持显示，直到下一段台词开始。
- 台词页面可上下滑动查看完整台词。
- 点击任意台词段落，可跳转到该段对应时间继续播放。
- 当前播放段会在台词页高亮并随播放进度滚动。

## 列表编辑

- 作品列表支持长按某个作品并拖动到目标位置，松开后保存作品顺序。
- 音轨列表支持长按某一首并拖动到目标位置，松开后保存音轨顺序。
- 移动中的条目会高亮显示，排序会在下次启动时继续保留。
- 作品列表已优化滚动性能：复用列表行、缓存封面缩略图，并在后台解码图片。

## 安装

在 GitHub Release 中下载最新 APK，例如：

```text
ASMR-Player-v1.3.0-debug.apk
```

复制到安卓手机后，允许安装未知来源应用即可安装。当前发布包为 debug 签名 APK，适合个人测试和侧载安装。

## 构建

本工作区已经安装了本地 Android SDK 和 Gradle 发行包，可直接执行：

```powershell
.\build-apk.ps1
```

脚本会执行 `clean assembleDebug lintDebug` 并生成安装包。
